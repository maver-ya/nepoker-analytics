# Сайт аналитики неПокера

Открыть: `index.html` (двойным кликом) или `python -m http.server --directory site`.

## Структура
- `index.html`, `style.css`, `app.js` — сайт (без внешних библиотек)
- `data/data.js`, `data/data.json` — данные (генерируются)
- `build_data.py` — сборка данных из Excel

## Как добавить турнир
1. Положить таблицу в `2026/<папка турнира>/` и обновить `Данные/Рейтинг ЦИФЕРБЛАТ.xlsx`.
2. Добавить запись в `TOURNAMENTS` в `build_data.py` (папка, столбец итога, базовый бонус, множители трофеев).
3. `python build_data.py` — смотреть замечания в конце вывода.
4. Если один человек записан по-разному — добавить пару в `ALIASES`.

## Финалы 2025 года
Лежат в `finals2025/*.txt` (набраны вручную по картинкам таблиц из чата и по истории сайта результатов). Формат: шапка `ключ=значение`, затем `[stacks]` (имя и стек на строку) и `[places]` (имена по порядку мест). Новые файлы нужно добавить в `F25META` в `build_data.py`.

## Межсезонка
Серии за 2023–2026 берутся из Excel («Архив» и «Межсезонка»), текущая серия — с сайта результатов:
```
python fetch_site.py     # скачивает данные дней, охоту и прирост рейтинга в interseason/current.json
python build_data.py
```

Быстрое обновление без Excel (только межсезонка и рейтинг после неё): `python update_site.py`.
На GitHub то же делает `.github/workflows/update.yml` — раз в сутки в 06:00 UTC и по кнопке «Run workflow» (коммитит `data/` и `interseason/`, если что-то изменилось).

## Проверки данных
После каждой сборки `build_data.py` печатает замечания и кладёт их в `data.json` (`checks`, `checks_summary`): похожие ники (возможные дубли), игроки межсезонки без финалов, совпадение рейтинга с сайтом результатов, турниры без стеков. Всё видно на странице «О данных»; число замечаний — в подвале сайта.

## Разделы сайта
Обзор · Турниры · Игроки (профиль: форма, сильные/слабые стороны, межсезонки, печать в PDF, картинка для шаринга) · Рейтинг (`#rating`, `#rating/Имя`) · Межсезонка · Интересное (`#fun`: номинации, метрики стека, охота) · Ещё: Карта, Сравнение, Зал славы (`#fame`), Отчёт, О данных.
Старые ссылки `#metrics` и `#hunt` перенаправляются в «Интересное».
